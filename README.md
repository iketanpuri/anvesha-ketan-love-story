# Ketan ♡ Anvesha

A personal, mobile-friendly love story with a Diwali welcome, pink and cream design, ten Polaroid memories, an interactive 3×3 photo puzzle, a Hinglish love letter and little notes.

## Open locally

Open `index.html` in a modern browser. Keep the `photos` folder alongside it. No build or installation is required. Optional Google Fonts need internet access.

## Photo puzzle

Tap two pieces to swap them, or drag and drop on desktop. Includes a move counter, timer, shuffle, photo hint and completion celebration.

## Personal photos

This repository contains personal photographs and is intended to remain private.
